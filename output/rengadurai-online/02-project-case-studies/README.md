# Category 2: Project Case Studies — GAP

Per the Content Strategy Brief §8, this is the brand's highest-trust
format: one full video per real, named project.

**Required structure (per brief):**
1. Project identity — location, type, size/value range
2. Client context — what the client wanted
3. Site/design challenge
4. Rengadurai's decision-making
5. Construction/interior/real estate lesson
6. What similar clients should learn
7. CTA for qualified enquiries

**Named projects available to draw from (per brief §8, Category 1):**
- 7000 sqft sea-facing villa, Palavakkam
- Two villas with pools: ~₹1cr and ~₹1.5cr
- ₹3cr villa, Nolambur
- ₹5cr individual house, Mandaveli
- ₹2cr individual house, Parithipattu
- ₹2.5cr service apartment project, Velachery (mentioned in example
  titles, §8 Category 2)

**Why nothing is drafted yet:** a real case-study script needs real
facts — what the client actually wanted, the actual site/design
challenge, the actual decisions made. Writing this from the project name
and value alone would mean inventing specifics about a real, identifiable
project, which isn't something to do without the actual details.

**To unblock:** provide, for one project to start with — client context
(what they wanted, any constraints), the specific site/design challenge
faced, and the key decisions made during design/construction. A script
can be drafted the same session once that's available.
