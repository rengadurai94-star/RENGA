# Templates

| File | Use |
|---|---|
| `Email_Automation_Database_Template.xlsx` | Reference copy of the Google Sheets database (all sheets, columns, default settings, your content as Draft). You don't need to upload it: **Setup / Repair System** creates the same structure in your Google Sheet automatically, with formatting, dropdowns and triggers. |
| `contacts_import_template.csv` | Example import file. Only the email column is required; column names are recognised automatically. |
| `email-content/dubai-20yr-certification.html` / `.txt` | Your email (HTML and plain-text versions) exactly as loaded into content CT-001. |
