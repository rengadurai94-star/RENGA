Import contacts from a file

Choose a .csv, .xlsx or .xls file. The first sheet is imported.
Recognised columns (any order, any of these names): Email (required), Company, Contact Person / Name, Building, Tags, Permission, Notes. A file with only one column of emails works too.

Invalid addresses, duplicates (already in Contacts) and addresses on the Suppression List are skipped automatically. Imported contacts get Permission = "Business Contact" unless the file says otherwise (change the default in Settings).
