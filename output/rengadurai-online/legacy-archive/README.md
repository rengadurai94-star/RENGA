# Legacy Archive — Mass-Market Content (Do Not Use As-Is)

Everything in this folder was written before the Content Strategy Brief
repositioned Rengadurai Online toward a premium/high-ticket audience. It's
kept for reference and possible reuse, not for direct publishing.

## Why these were archived

Per brief §7 ("Past Mistakes To Correct"), this content has the exact
pattern the brief identifies as the core problem:

- **DIY-checklist / mistake-avoidance framing** ("here's how you check
  X yourself") instead of case-driven authority framing ("here's what I
  caught/decided on a real project")
- **Budget/mass-market language** ("40 lakh house," "low budget," basic
  construction tips) instead of premium-decision language
- **Weak, generic CTAs** ("comment price" / "connect via description")
  instead of the audience-specific CTAs in brief §12

## Possible future use

Brief §15 (Monthly Content Mix) allows "2 general construction education
posts, but framed for premium decision-making" per month. Some of these
topics (plot legal checklist, cost transparency) could fill that slot —
but only after the same voice treatment the VKP series got: cut
DIY-instructional framing, add case/principle-driven delivery, fix the
CTA. None of that rewrite has been done yet.
