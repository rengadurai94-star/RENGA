# Category 5 (Brief) — Real Estate Investment Intelligence

Per the Content Strategy Brief §8, Category 5.

**Purpose:** attract ₹1cr+ investors; build future authority for
REIT/investment-related work.

**What exists:**
- `evaluating-real-estate-investment-script.md` — 9-10 min standalone
  covering apartment vs land vs plotted development, rental yield vs
  appreciation, liquidity/resale risk, title/approval/loanability/
  litigation risk, a 4-pillar "safe asset" framework.
- `reits-in-india-explained-script.md` — 9-10 min standalone, the
  full REITs treatment flagged as missing in the first script: what a
  REIT is, how it differs from direct property ownership, what it
  actually owns, risk considerations, who it suits. Cross-referenced
  with the framework script both ways.

**Topics still not covered (future videos):**
- Any case-study-style investor content (needs real client/transaction
  facts, same constraint as Category 2)

**Tone constraint (important):** educational, careful, evidence-based.
**Do not promise returns.** Both existing scripts stay strictly in "how
to evaluate" / "how this works" territory, not "here's what you'll
earn" — no ROI percentages or guarantees anywhere in either.

**Adjacent existing content:** `../05-landowner-jv/land-banking-jv-development-script.md`
touches JV economics from the landowner's side (Category 4), which is a
different angle than this investor-facing category.
